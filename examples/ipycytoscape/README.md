## ipycytoscape app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Fipycytoscape%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_ipycytoscape` adds over a static network plot: an interactive graph you can pan, zoom and drag nodes in, node click callbacks that update reactive values, and changing the layout or styles in place without re-rendering the graph.

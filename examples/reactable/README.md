## reactable app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Freactable%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_reactable` adds over a static table: [reactable](https://machow.github.io/reactable-py/)'s sorting, filtering, searching, pagination, row grouping/aggregation, and formatting all run client-side, and non-data props (like the page size here) update in place from Python without re-rendering the table.

## itables app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Fitables%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_itables` adds over `@render.data_frame` and `@render.table`: itables' [DataTables](https://datatables.net) features (e.g., column ordering and search, row selection, buttons, and many other options) with the browser-side `selected_rows` state readable from Python via `reactive_read()`, in a table that fills its container.

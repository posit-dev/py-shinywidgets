## jscatter app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Fjscatter%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_jscatter` adds over static or SVG scatter plots: GPU-accelerated rendering of very large numbers of points, and point selection (lasso, click) that comes back to Python as a reactive value, so brushing one plot can drive other plots, tables, and any other Shiny output.

## plotnine app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Fplotnine%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_plotnine` adds over `@render.plot`'s static image: zooming and panning, and matplotlib event callbacks (e.g., clicking a point) that run in Python and can update the figure in place without losing the current view.

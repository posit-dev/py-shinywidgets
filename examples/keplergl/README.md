## kepler.gl app

<a href='https://connect.posit.cloud/publish?framework=shiny&sourceRepositoryURL=https%3A%2F%2Fgithub.com%2Fposit-dev%2Fpy-shinywidgets&sourceRef=main&sourceRefType=branch&primaryFile=examples%2Fkeplergl%2Fapp.py&pythonVersion=3.11'><img src='https://cdn.connect.posit.cloud/assets/deploy-to-connect-blue.svg' align="right" /></a>

What `@render_keplergl` adds over exporting a kepler.gl map to static HTML: the full interactive kepler.gl interface (layers, filters, and basemaps in its side panel) driven by reactive Shiny inputs, and the map's configuration syncing back to Python through `reactive_read()`.
